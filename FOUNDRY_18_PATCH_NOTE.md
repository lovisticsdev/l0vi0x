# Foundry 1.8.3 compatibility / acceptance note

The M1a implementation contains the Foundry 1.8.3-specific trace adapter and sanitized configuration work reviewed during the audit.

This note is **not** an acceptance certificate. Live acceptance still requires the pinned Foundry/Anvil/solc toolchain, verified tool hashes, real local and fork execution, and successful three-run certificate issuance through the complete replay pipeline.
